# Aether OS Portfolio

A standalone React + Vite portfolio designed from the Aether OS styling you shared.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL Vite prints.

## Deploy to your existing GitHub Pages repository
1. Put these files in the root of `kk63bit/karthik-portfolio`.
2. Commit and push to the `main` branch.
3. In GitHub, open Settings → Pages and select **GitHub Actions** as the build and deployment source.
4. Open Actions and wait for “Deploy portfolio to GitHub Pages” to finish.
5. Visit https://kk63bit.github.io/karthik-portfolio/

`vite.config.js` is configured for `/karthik-portfolio/`.

## Before publishing
- Replace `hello@visionvault.example` in `src/App.jsx` with a public email address you want to share, or remove the email button.
- Update the project descriptions and milestones to match your real work.
- This is a static site: no secure admin login, server database, or automatic YouTube API syncing is included.


## Vision Vault images
Place the channel icon, banner, and creator artwork in `public/images/` using these filenames: `vision-vault-logo.png`, `vision-vault-banner.png`, and `vision-vault-creator.png`. These are included in this package.
